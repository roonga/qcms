Task 101: the rest of the admin Site configuration area.

- Site administrators lists every Site administrator, finds an account to promote, and promotes or demotes in a step-up dialog named for the act. The last active Site administrator cannot be demoted, an unclaimed account cannot be promoted, and a held act says it waits for another Site administrator.
- Approval requests lists site and workspace requests, pending by default and filterable by status and by where they were made. The requester and the target never get an Approve; approving a site request asks for a step-up, and a workspace request is decided through its own workspace.
- Site audit lists the site log with a kind filter, names each act in words, and shows a row the expiry sweep wrote as the system.
- New workspace names its first Workspace administrator by address and shows the four starter groups it opened with and a short checklist. Workspaces offers New workspace to a Site administrator and tags the shared question library.
