The links screen names what its copy controls copy.

- A minted secure link is copied from a control that reads Copy link rather than Copy URL.
- The public form link's icon control carries the same name, so its accessible name says
  what it copies instead of only the act.
- Each minted link's copy control is named by its position ("Copy link 3") while still reading "Copy link",
  so the controls are told apart by assistive technology.
