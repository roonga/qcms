## Collected material and limitations

PC8 itself is NOT included. reference.html is the official Morocco embassy instructions; pc8-guidance.pdf is a two-page Berlin embassy checklist, not the application. b11-general-declaration.pdf is the actual blank one-page supplementary B11 form (0925). The embassy explains that a blank PC8 cannot be printed from the portal; only completed applications can be printed. No application was started or personal data entered. Embassy guidance is location-specific and may be historical.

## Suggested test scenarios

- Separate an applicant from the person making a declaration; include the applicant name when they differ or the application is for a child.
- Preserve international address/phone fields and the free-text statement in B11.
- Keep the physical-signature requirement and supporting-document instructions; do not infer a complete PC8 question set from the checklist.

These are manual evaluation targets, not implemented tests or validated QCMS definitions. Compare any future extraction with the original wording, answer choices and explicit routing. Use synthetic answers only.
