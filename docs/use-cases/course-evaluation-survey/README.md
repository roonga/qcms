## Suggested test scenarios

- Keep the five ordered agreement labels attached to every rating row.
- Separate course, provider and instructor metadata from evaluation responses.
- Retain optional comments and distinguish a missing rating from the neutral response.

These are manual evaluation targets, not implemented tests or validated QCMS definitions. Compare any future extraction with the original wording, answer choices and explicit routing. Use synthetic answers only.
