## Collected material and limitations

source.html is an unchanged HTTP capture of the public FIRST STEP only. It contains contact-channel and service ratings, comments and contact details. No Next button was used and later steps are NOT captured. CSS, JavaScript, images, lookup services and validation endpoints are not bundled. The snapshot is a parsing reference, not an offline working survey; do not submit it.

## Suggested test scenarios

- Extract the contact-channel selector and advisor/service rating controls with their option text.
- Preserve the 100-character enquiry limit and required versus optional contact inputs.
- Recognize the Next button as evidence of uncaptured steps rather than inferring the complete survey.

These are manual evaluation targets, not implemented tests or validated QCMS definitions. Compare any future extraction with the original wording, answer choices and explicit routing. Use synthetic answers only.
