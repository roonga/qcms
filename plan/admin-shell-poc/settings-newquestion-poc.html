Screen

Two form-dense QCMS admin screens: Settings (account, password, two-factor status and the one-time recovery-code reveal, split into three rail-navigated sections rather than one long stack) and New question (the only screen where a question's id and type are ever chosen, shown here with the choice type selected so the shipped option grid is visible, and still main-only - it is one form, not several sections). Switch between them with the control above.
