Admin shell POC: the shipped top nav and a left rail that navigates between two real screens, form-level and step-level, matching the data model's own boundary (a step is only a title and its pinned questions). The Form screen stacks the form title, form settings, a compact Rules lens, the rule test bench and Validation. The Step screen holds only the step's own title and its questions grid (an option-grid-style table replacing stacked pin cards).
