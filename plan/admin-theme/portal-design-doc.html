Portal design doc

The respondent-facing questionnaire seat: adopter-themeable, mobile-first, and built so a respondent's own accessibility needs (colour, font, spacing) are first-class runtime controls rather than a one-time operator choice. The Theme, Mode, and Density controls above are live: they set data-theme / mode classes / density classes on <html>, and this whole page (Sample and Components sections included) reads the same tokens the shipped portal reads, so what you see here is what a respondent sees, not an approximation of it.

01 / Respondent-first

Goals

The portal optimises for one person: the respondent, on whatever device and under whatever brand they landed on. Every decision below follows from that.

  • Adopter theming without forking
    Four predefined themes (Slate Teal default, Harbor Blue, Sand Terracotta, Plum Violet) cover most brands out of the box; re-skinning is a token swap, never a code change.
  • Respondent accessibility controls as first-class
    Colour mode (light / dark / high-contrast), font, and density are runtime choices the respondent makes, not settings buried in the QCMS app. System-default font is always on the list as the escape hatch.
  • WCAG 2.2 AA everywhere, AAA in high-contrast
    Every text/background pair in every theme and mode is contrast-checked against these floors by build.py, not eyeballed.
  • Comfortable touch scale
    44px control height by default (Comfortable density); Compact never drops below 36px, well above the 24px WCAG 2.5.8 floor.
  • Corners as a theme-level, operator-set character
    Subtle radii ship as the portal default. Sharp / Rounded / Pill exist in the registry for operator brand choices, but are not a respondent control.
  • Mobile-first, SSR no-flash
    One column, no horizontal scroll. The chosen theme / mode / font / density classes are applied server-side on the root element before first paint (task 053), so there is no flash of the default theme.
02 / Registry

Four themes, light and dark

Slate Teal is the shipped default: a muted blue-green, professional and brand-neutral. Harbor is a corporate mid-blue, Sand a warm terracotta neutral, Plum a deep violet. Light and dark are independent per-theme palettes; every pair below clears WCAG 2.2 AA (body text >= 4.5:1), verified by build.py against the exact values in tokens.css - see THEMES.md for the full per-pair contrast tables. High-contrast is not per-theme; it is one shared universal layer covered in Axes below.

Rendering note: the grid below hardcodes each cell's hex fills rather than scoping data-theme / .dark to each cell, because the registry's selectors target :root only (an alternate theme cannot be scoped to a nested element). Every hex value shown is copied verbatim from tokens.css.
