QCMS app default font, candidates

Decision 2026-07-30: Lexend chosen.

The QCMS operator shell (Questions, Forms, Responses, and the rest of the authoring seat) currently renders in the plain system font stack, shown first below as the baseline. The five candidates that follow are all OFL or Apache licensed and self-hosted as woff2, embedded here as data URIs the same way they would ship in production (no CDN hotlink is possible under the app's CSP). Unlike the Portal, operators get no font switcher: this card picks the app's one shipped face. The system stack shown first is a comparison baseline and the @font-face fallback only, not a selectable option.
