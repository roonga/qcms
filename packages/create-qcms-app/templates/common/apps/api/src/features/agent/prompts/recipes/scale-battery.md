# A battery of statements on one scale

**Use for:** a block of statements sharing one set of answers: a five point agreement matrix, the five WHO-5 statements over six frequency choices, a set of service ratings.

**Settings**

- One `singleChoice` question per statement, each carrying the full set of scale options with the same option ids and the same wording throughout the block. Do not shorten the options on the later rows.
- Put them in one step, in the source form's order, so they read as a block.
- The step title carries the shared instruction and the recall period: "For each of the following, please say how much of the time you have felt this way over the last two weeks."
- `required` set the same way across the block.

**Cannot be expressed**

- A matrix, grid or table layout for a set of questions. The table layout exists only for a repeating group, which is one set of questions answered once per thing, and a battery is not that: the statements differ, so each is its own question.
- Column headings shown once above the block. The scale labels repeat on every statement.
- A score, a total or a subscale over the block.
- A recall period as a property of the questions. It is prose in the step title or in each question's `help`.

**Say this**

> Each statement is its own question, and every one carries the full set of answers. The shared answer headings cannot be shown once across the top, so the answers repeat on each line. The instruction and the two week period sit in the heading of the page.

**Corpus sources:** WHO-5 wellbeing survey (five statements, six ordered choices as a rating matrix, two week recall period, scoring instructions kept apart from answer fields), Course evaluation survey (five point agreement matrix over multiple instructor rows), CAHPS health plan experience survey.
