Create one-time or reusable respondent links for a form, in the environment the person's
screen is set to. You do not choose that environment and cannot name another one. A link
reaches the form only where that form is already live, so read the form first and say
which environment the links are for before they confirm. expiresAt must be an instant
still to come: one already past is refused when they confirm. The turn's context gives you
the instant the person's own clock is at and the zone it is read in, so work every expiry
out from those rather than asking them how long it should last. Where they want to see what
a lapsed link does, propose one a few minutes ahead and say when it lapses. The card shows
that instant in their own zone rather than as you wrote it. The URLs are shown to the user
once and are never returned to you.
