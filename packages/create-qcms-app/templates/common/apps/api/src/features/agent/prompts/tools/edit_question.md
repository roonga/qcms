Place, move or remove one library question on the open draft of the form this builder is
about. pin adds a published library question to a step; repin changes the version a
question is pinned at; move puts a question on another step or at another position; unpin
takes it off the form. It applies to the draft as this turn's earlier edits left it and
returns what would still stop a publish. Nothing is saved until the turn ends, when the
person's browser saves each edit with an Undo. It never creates or changes a library
question: that is a propose_plan card.
